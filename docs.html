Документация API

Распознавание текста на изображениях. Базовый адрес https://eztext.noip.at/api.

Авторизация

Получите ключ командой /key в @eztextbot. Передавайте ключ в заголовке Authorization: Bearer <ключ>. Повторная команда /key заменяет текущий ключ. Храните его на сервере или в переменной окружения.

Распознавание

POST /v1/ocr?lang=rus%2Beng

Загрузите JPEG, PNG или WebP в поле image. Отправку исходных байтов в теле запроса тоже можно использовать. Максимум 5 МБ и 16 мегапикселей. Допустимые языки rus, eng и rus+eng (по умолчанию). Кодируйте знак + в URL как %2B.

curl https://eztext.noip.at/api/v1/ocr \
  -H "Authorization: Bearer $EZTEXT_API_KEY" \
  -F "image=@photo.png"

Ответ 200

{"text":"Пример распознанного текста","language":"rus+eng"}

Обработанное изображение расходует один запрос, даже если текст не найден. В этом случае поле text пустое.

Баланс и история

GET /v1/balance

Возвращает остаток платных (credits) и бесплатных (free) запросов. После создания своего OCR-бота 10 бесплатных запросов в час делятся между Telegram и API.

{"credits":30,"free":10}

GET /v1/history

До 100 последних распознаваний через API и Telegram. source обозначает источник (api или telegram). at — Unix-время в секундах, duration_ms — время обработки в миллисекундах.

{"requests":[{"at":1795600000,"status":200,"language":"rus","duration_ms":430,"source":"telegram"}]}

GET /health

Проверка доступности без ключа.

Ошибки

API возвращает JSON с полем error.

HTTPПричина и действие
400Неподдерживаемый язык или некорректное изображение. Проверьте файл и параметр lang.
401Ключ отсутствует или недействителен. Проверьте заголовок авторизации.
402Нет доступных запросов. Создайте своего бота через /mybot или пополните баланс через /buy.
413Файл превышает лимит размера.
429Бесплатный часовой лимит исчерпан. Дождитесь его обновления или пополните баланс.
503Распознавание временно недоступно. Повторите запрос через несколько секунд.
